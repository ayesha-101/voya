# ڤويا ستور — VOYA STORE

متجر إلكتروني عربي (RTL) لمنتجات العناية العضوية، مبني بـ **Next.js 16 + React 19 + Tailwind CSS 4**.

> منتجات مختارة بعناية وبأعلى جودة — *Carefully Selected Products with High Quality*

## التشغيل

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # بناء الإنتاج
npm start       # تشغيل نسخة الإنتاج
npm run lint
```

## الصفحات

| المسار | الوصف |
| --- | --- |
| `/` | الرئيسية: هيرو، مزايا، تصنيفات، الأكثر مبيعًا، بانر عرض بعدّاد، عروض خاصة، آراء العملاء، نشرة بريدية |
| `/products` | قائمة المنتجات مع فلترة بالتصنيف، بحث نصّي، وخمسة أنواع فرز |
| `/products/[slug]` | صفحة المنتج (مولّدة ثابتًا لكل منتج) |
| `/cart` | السلة: تعديل الكميات، حذف، حساب الشحن والإجمالي |
| `/checkout` | إتمام الطلب: بيانات التوصيل + الدفع عند الاستلام |
| `/about` `/contact` | من نحن، تواصل معنا + الأسئلة الشائعة |
| `/shipping` `/returns` `/privacy` | صفحات السياسات |

## بنية المشروع

```
src/
├── app/               # صفحات App Router
├── components/        # مكوّنات الواجهة
│   ├── Header.tsx     # هيدر لاصق + بحث + قائمة جوال + عدّاد السلة
│   ├── ProductArt.tsx # صور المنتجات مولّدة SVG محليًا (لا ملفات خارجية)
│   └── useCart.ts     # واجهة السلة للمكوّنات
├── data/
│   ├── site.ts        # ← إعدادات المتجر: الاسم، العملة، واتساب، حد الشحن المجاني
│   └── products.ts    # ← الكتالوج: التصنيفات والمنتجات
└── lib/
    ├── cartStore.ts   # مخزن السلة (useSyncExternalStore + localStorage)
    └── format.ts      # تنسيق الأسعار
```

## التخصيص السريع

- **هوية المتجر** (الاسم، الهاتف، واتساب، البريد، رسوم الشحن): `src/data/site.ts`
- **المنتجات والتصنيفات**: `src/data/products.ts`
- **الألوان والخطوط**: كتلة `@theme` في `src/app/globals.css`
- **الشريط المتحرك العلوي**: مصفوفة `announcements` في `src/data/site.ts`

## صور المنتجات

الصور حاليًا **مولّدة كـ SVG** داخل `ProductArt.tsx` — يعمل المتجر بلا أي ملفات صور.
لاستخدام صور حقيقية: أضف `image: "/products/xxx.webp"` لكل منتج في `products.ts`،
ثم استبدل `<ProductArt />` بـ `<Image />` من `next/image` في `ProductCard.tsx`
وفي `src/app/products/[slug]/page.tsx`.

## ما يحتاج ربطًا قبل الإطلاق

هذه واجهة متجر كاملة تعمل على العميل. للإطلاق الفعلي:

1. **حفظ الطلبات** — `submit` في `src/components/CheckoutForm.tsx` يولّد رقم طلب محليًا فقط.
   استبدله بنداء إلى Route Handler (`src/app/api/orders/route.ts`) يكتب في قاعدة بيانات.
2. **بوابة الدفع** — خيار «بطاقة ائتمانية» معطّل حاليًا؛ اربطه بـ Stripe أو Tap أو Checkout.com.
3. **النشرة البريدية ونموذج التواصل** — لا يرسلان بريدًا بعد.
4. **المخزون** — `stock` بيانات ثابتة؛ اربطه بمصدر حقيقي لمنع بيع منتج نافد.
